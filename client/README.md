# BIT Campus Connect

Project Title

BIT Hostel Room Allocation System and Roommate Compatibility Matchmaking Portal

Project Description

Build a modern, responsive, attractive frontend for a web application called BIT Hostel Room Allocation System and Roommate Compatibility Matchmaking Portal.

The application is designed for students of Bannari Amman Institute of Technology (BIT) to simplify hostel room allocation and help students find compatible roommates based on their lifestyle and preferences.

The design should look similar to modern websites like Airbnb, Notion, and Microsoft with smooth animations, rounded corners, glassmorphism effects, gradients, shadows, and a professional UI.
